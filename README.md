# 像素沙盒小游戏

一个可以在浏览器里直接玩的像素风格沙盒放置小游戏。

## 在线试玩

> GitHub Pages 链接：
> `https://xiaozhenweiyan.github.io/game/`

## 玩法说明

1. 打开页面后，画布会自动填满整个浏览器窗口。
2. 用鼠标左键在画布上点击或拖动，即可放置当前选中的方块。
3. 点击右下角的切换按钮，可以在多种方块类型之间循环切换：
   - **水方块**（蓝色）：受重力下落，落到底部后会向左右流动并堆叠，形成简单的流体效果。
   - **泥土方块**（棕色）：放置后静止不动，不受重力影响，适合用来搭建地形。
   - **种子**（浅绿色）：放在泥土上方会在3秒后生长成树（包含木头和树叶）。
   - **木头**（深棕色）：固定方块，可燃，燃烧后变成木炭。
   - **树叶**（绿色）：固定方块，可燃，燃烧后消失。
   - **火**（橙色）：会点燃相邻的木头和树叶，燃烧2秒后熄灭；遇到水会被扑灭。
   - **木炭**（深灰色）：木头燃烧后的产物，不可燃。
4. 点击左下角的模式切换按钮，可以在「放置模式」和「删除模式」之间切换：
   - **放置模式**：点击或拖动鼠标放置方块（默认模式）。
   - **删除模式**：点击或拖动鼠标删除方块。
5. 点击切换按钮不会误放置方块，请放心操作。

## 本地运行

```bash
python3 -m http.server 8080
```

然后在浏览器中打开 `http://localhost:8080/` 即可。

## 技术栈

- HTML5 `<canvas>`
- 原生 JavaScript
- 纯 CSS 样式
