# 像素沙盒小游戏

一个可以在浏览器里直接玩的像素风格沙盒放置小游戏。

## 在线试玩

> GitHub Pages 链接：
> `https://xiaozhenweiyan.github.io/game/`

## 玩法说明

1. 打开页面后，先在登录界面输入昵称创建临时账号（仅本地保存，无需密码）。
2. 登录后进入主菜单：
   - **开始游戏**：进入单人沙盒模式。
   - **进入房间**：输入房间码加入联机房间。
3. 进入游戏后，画布会填满整个浏览器窗口。
4. 用鼠标左键在画布上点击或拖动，即可放置当前选中的方块。
5. 点击右下角的方块按钮，会弹出**背包栏**面板，可在其中选择任意方块：
   - **水方块**（蓝色）：受重力下落，落到底部后会向左右流动并堆叠，形成简单的流体效果。
   - **泥土方块**（棕色）：放置后静止不动，不受重力影响，适合用来搭建地形。
   - **种子**（浅绿色）：放在泥土上方会在3秒后生长成树（包含木头和树叶）。
   - **木头**（深棕色）：固定方块，可燃，燃烧后变成木炭。
   - **树叶**（绿色）：固定方块，可燃，燃烧后消失。
   - **火**（橙色）：会点燃相邻的木头和树叶，燃烧2秒后熄灭；遇到水会被扑灭。
   - **木炭**（深灰色）：木头燃烧后的产物，不可燃。
   - 点击背包栏外部区域或再次点击按钮可关闭面板。
6. 点击左下角的模式切换按钮，可以在「放置模式」和「删除模式」之间切换：
   - **放置模式**：点击或拖动鼠标放置方块（默认模式）。
   - **删除模式**：点击或拖动鼠标删除方块。

## 联机玩法

游戏使用 PeerJS（WebRTC P2P）实现联机，无需服务器，直接在两位玩家之间同步世界。

- **创建房间**：进入游戏后，点击右上角「创建房间」按钮，会生成一个格式为 `XXXXX-XX` 的房间码（如 `ABCDE-12`）。把房间码告诉朋友即可。
- **加入房间**：在主菜单点击「进入房间」，输入房主给的房间码，校验通过后会自动连接。
- **世界同步**：两位玩家在同一房间时，任意一方放置或删除方块，操作都会实时同步到对方画面（右上角显示房间码和在线状态）。
- **降级处理**：若 PeerJS 服务不可用或连接失败，会给出提示但不影响单人游玩。
- **限制**：每个房间为 1v1，房主退出即销毁房间。

> 注意：联机依赖 PeerJS 公共信令服务器，首次创建/加入房间需要联网。

## 本地运行

```bash
python3 -m http.server 8080
```

然后在浏览器中打开 `http://localhost:8080/` 即可。

## 技术栈

- HTML5 `<canvas>`
- 原生 JavaScript
- 纯 CSS 样式
- PeerJS（WebRTC P2P，用于联机世界同步）
